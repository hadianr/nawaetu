# antislop fix report 005: axe-core re-sweep

**Date:** 25 November 2026
**Why:** the last check after fix report 004 was a full axe-core 4.14 run (WCAG 2.0 to 2.2 A and AA) as a guest, on the local dev server built from `main`.

**Coverage:** 26 routes × 5 themes (Daylight, Emerald, Midnight, Sunset, Blossom) at 390px in Indonesian, plus all 26 routes in English at 320px with overflow, `<h1>`, `<main>` and `lang` checks. That is 156 page loads.

## Found and fixed

| Where | Problem | Fix |
| --- | --- | --- |
| `/missions`, all themes | Locked missions faded the whole row to 60% opacity. Title, ruling chip and lock reason fell to 2.6:1 to 4.4:1. The row still opens its detail dialog, so it is an active control. | The row keeps its subtle background and dimmed icon. Its text uses the normal colours. |
| `/missions`, Indonesian | Lock and late reasons were hardcoded English ("Available at 15:00"). | Reasons carry a code and parameters, and the page fills an en/id template: "Tersedia pukul 15:00". |
| `/quran/[id]`, all themes | The previous and next surah numbers sat at 20% opacity (1.4:1 to 1.9:1). | Muted text colour, strong on hover |
| Home, all themes | The 30-day journey ring had `role="progressbar"` but no name. | `aria-label` with the card title. The streak milestone bar got the same fix. |
| `/design-system`, Blossom | `text-primary` uses Blossom's pale pink in light mode (2.1:1). `ui/button`'s link variant used the same class. | `primary-strong` |
| `/design-system`, 320px | A long token name overflowed its row. | `break-all` |

## Clean

- After the fixes, a re-run of the affected routes in all five themes found no axe violations, and no overflow at 320px.
- Every route at 320px has exactly one `<h1>` and one `<main>`, with `lang="en"`. Nothing overflows except the token name fixed above.
- Card shadow: all 2,736 card elements found across the run render `--shadow-card`. In the dark themes it is `0 4px 20px rgb(0 0 0 / 0.24)`, so the dark-theme card check from fix report 004 is done.
- `npm run typecheck`, `npm run lint`, `npm run test:run` (997 passed).

## Second pass: dialogs, focus and hover

The scan clicked every non-destructive button on 18 guest routes, so each dialog it found opened at least once. That came to 43 distinct dialogs. Each open dialog was checked with axe in all five themes, and so was whether focus moved into it and whether Escape closed it. Buttons that share, pay, delete, sign in, complete or send were skipped, and so were buttons inside forms.

| Where | Problem | Fix |
| --- | --- | --- |
| Mission detail, mission list, tafsir | The X close button had no name. | `aria-label` |
| Quran display settings | The transliteration and word-by-word switches had no name. | `aria-label` |
| Dialogs with a `ScrollArea` | The scrolling region could not be reached by keyboard. | The viewport is focusable (`ui/scroll-area`). |
| Dhikr stats | Hardcoded Indonesian, id-ID numbers, and text dimmed by opacity (3.2:1 to 4.4:1) | en/id keys, locale numbers, muted colour |
| Dhikr list | The title was at 40% opacity, and muted text on the selected row was 4.49:1 in Sunset. | Muted colour; a lighter selected background |

- Focus: every opened dialog took focus and closed on Escape.
- Focus ring: all 853 focusable elements show a ring. The two search inputs only looked flat because their ring transitions in.
- Hover: every `:hover` rule was applied at once, and the colour-contrast rule found nothing in any theme.

## Found while checking the dhikr counter

- Long dhikr such as Sayyidul Istighfar sat in a `pointer-events-none` layer, so they could not be scrolled. Their transliteration and meaning were also cut with "...". The text now scrolls, and the data is complete: the wording matches the dua library entry, HR. Bukhari No. 6306.
- The completion dialog drew the check and then, about 0.5 s later, played sparkles over it. It now shows only the check.
- The mission list dropped its +N Hasanah chip. The chip took about 92 of 343 px per row. The reward still shows in the dialog, on the complete button and in the toast.
